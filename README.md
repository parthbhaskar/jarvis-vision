# PROJECT JARVIS VISION (Windows Edition)
> A Real-Time, Multimodal AI Systems Assistant combining Edge IoT Visual Ingestion with Cloud Cognitive Reasoning and Windows OS Automation.

## System Overview
- **Visual Grounding:** Optical ingestion directly from GoPro HERO9 Black over direct USB-Ethernet UDP stream at 720p HD.
- **Acoustic Interaction:** Real-time conversational audio pipeline using native multimodal audio and high-fidelity neural speech synthesis.
- **Deterministic Windows Control:** Safe execution sandbox utilizing Windows Management Instrumentation (WMI) and PowerShell process dispatching.
- **Zero Local LLM Bloat:** Cloud-offloaded reasoning ensures sub-2-second roundtrip latency with minimal memory footprint.

## Engineering Stack
- **Platform:** Windows 11 (x64)
- **Runtime:** Python 3.11
- **AI Engine:** Google GenAI SDK (`gemini-3.5-flash-lite`)
- **Computer Vision:** OpenCV Headless, Pillow
- **Speech Synthesis:** Microsoft Edge Neural Voice API
- **System Automation:** PowerShell, Windows Management Instrumentation (WMI/CIM)
